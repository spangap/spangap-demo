# spangap-demo — the Spangap reference buildable

`spangap/spangap-demo` is one component of the [**Spangap**](https://github.com/spangap)
platform: the **buildable** that assembles a reference device image. It is not
the platform itself — the runtime, IP/web stack, LCD UI, remote-access services
and viewer each live in their own straddles. For what Spangap is and the full
set of components, read the **[org README](https://github.com/spangap)**.

## What this straddle does

The buildable carries no firmware or board HAL of its own — it is the assembly
point. It ships the browser SPA (`web-interface/`), the LittleFS data image
(`data/`), the LCD launcher icons (`assets/lcd-icons/`) and the on-device user
manual (`esp-idf/data/webroot/WELCOME.md`, which overrides the viewer
straddle's generic welcome page as the viewer's home document — it lives under
`esp-idf/`, registered via `SPANGAP_EXTRA_DATA_DIRS` in
`esp-idf/CMakeLists.txt`, so it merges after every staged straddle's own data
and wins collisions). It pulls in the **non-mesh** platform: `spangap-net` (which
also brings the remote-access
services — ACME, DuckDNS, UPnP, WireGuard, sshd), `spangap-web`, and `viewer`.
There is no Reticulum mesh here — that's the sibling [Reticulous](https://github.com/reticulous)
project. You build it *with* a board, which supplies the pin maps, bring-up
hooks and hardware kconfig; a board with a screen additionally installs the
on-device LCD UI.

Every component starts automatically when it is in the build — there is no
hand-written init sequence; the entry point is generated by the build.

## Building

```sh
spangap build spangap/spangap-demo --with spangap/hw-lilygo-tdeck   # LilyGo T-Deck Plus (screen → on-device UI)
spangap build spangap/spangap-demo                           # generic ESP32-S3 with PSRAM, headless
```

Leave off `--with` for a generic build that runs over WiFi on any ESP32-S3 with
PSRAM — browser and CLI access, no board-specific hardware.

Its image catalogues live in the workspace's `spangap-builds/` (from
`project: Spangap`), which `spangap flashmon` serves as `/builds` while this is
the straddle being built.
